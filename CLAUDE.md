# An Lantawan — project guide

An Lantawan is the official student publication of Leyte Normal University (LNU), Tacloban City. This repo is its new website, replacing anlantawan.wordpress.com: the public site, an admin for editors, Sportsfest coverage, and **Sumat** ("to tell"), an NGL-style page at `/sumat` where students message the newsroom, anonymously or with their name.

Owner: Francis Angelo Batiancela, Creatives and Multimedia Director. He approves every design before it is built, and maintains the code until he hands it to IT students.

## Stack

- **Astro** (server output) on **Cloudflare Workers**, free tier. Public pages and `/admin` live in one app. Svelte only for interactive admin parts.
- **Cloudflare D1** (SQLite) through **Drizzle ORM**. **R2** for photos and PDFs. **Cloudflare Access** guards `/admin` with Google sign-in.
- TypeScript strict, Zod at every input boundary, Vitest for logic, Biome for lint and format.
- Live preview: https://an-lantawan.anlantawan.workers.dev. Planned domain: a `lnu.edu.ph` subdomain from LNU ICT.

## Repository

```
src/core/        Rules with no database or web code: medal tally, standings, brackets, Sumat checks. Tested.
src/db/schema/   Tables and relations (publishing, sumat, sportsfest, site)
src/db/queries/  Database reads and writes, one file per area
src/pages/       Routes. src/pages/api/ for JSON endpoints
src/scripts/     Browser code for pages
migrations/      SQL migrations generated by drizzle-kit, applied by wrangler
```

- Layers only call downward: pages → core and queries → schema. Business rules live in `src/core`, never in a page or a query.
- Never store what can be computed: the medal tally, standings and "Latest" are derived.
- Nothing on the site is static copy. Text editors might change belongs in `settings`, `menu_items` or a table, editable from the admin.
- Archive (`archived_at`) instead of deleting stories, people, tribus and sections.
- Schema change: edit `src/db/schema`, run `npm run db:generate`, commit the new migration, apply with `npm run db:migrate:local` / `db:migrate:remote`.
- Commits: many small commits, one-line messages, nothing else in the message.

## Approved Sumat design (do not redesign without being asked)

Francis approved the v0 mobile screens: a single compose card and a "Sent." confirmation. `src/pages/sumat.astro` implements them. Match it exactly when extending. The rest of the site follows the Figma rebrand (square corners, Geist), not this.

- Colors: white `#FFFFFF` base; ink `#0A0A0A`; greys `#FAFAFA`, `#F3F3F1`, `#D6D6D3` (strokes), `#6B6B68` (secondary text); yellow `#FFE400` with a slight gradient to `#FFC700` ("sunrise", top to bottom).
- Yellow is a fill with black text on it, never text on white (fails contrast).
- Type: Helvetica Now Display for UI (Inter fallback on the web); Tungsten Condensed Bold for big display words like "SENT." (Anton fallback). Both brand fonts are licensed and installed on Francis's Mac but are not web-licensed, so the page uses `local()` with fallbacks.
- Shape: rounded. Cards 20px radius, inputs 12 to 14px, buttons and toggles fully rounded pills. 1px grey strokes.
- Logo: a faceted yellow torch with white seams on a grey shadow plane, in `src/components/Torch.astro` (viewBox `0 0 1015 1630`).

## Working with Francis

- Design happens in Figma first, in **Francis's own account** through the Figma plugin MCP (`mcp__plugin_figma_figma__*`, 2300563@lnu.edu.ph), not the claude.ai Figma connector (that one is a different account). Working file: https://www.figma.com/design/cHl3u8XKxPAssIgy7nLGZm
- Discuss before building when he asks to discuss. Present one recommendation, not a survey.
- He rejected several explorations as generic or forced: decorative suns, stamps, tilted planes, vertical spine wordmarks, giant mastheads, stock photography. Don't add imagery or motifs to make a page "feel designed". Start from the approved screens and change only what is asked.
- Load the `frontend-design` skill before design work and avoid template tells (tracked ALL-CAPS eyebrows everywhere, `A · B` meta strings, `01/02/03` on non-sequences, one highlighted word per headline).
- Copy: plain, sentence case, says what happens. Don't promise more privacy than the system gives: "anonymous" and "read only by the editorial team" are accurate. "Untraceable" is not.

## Checks before handing work back

- `npx biome ci .`, `npx astro check`, `npm test` and `npm run build` all pass (CI runs the same).
- New rules in `src/core` come with tests, including stress cases (ties, byes, more tribus, changed results).
- Headless Chrome screenshots at 390px and desktop width of every page touched. For Sumat: compose, "With my name", sent and closed states.
